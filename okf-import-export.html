What is Open Knowledge Format (.okf)?
OKF is an open, portable schema for personal AI memory management. It allows you to move your long-term memory traces, preferences, and privacy rules seamlessly between different local or cloud AI assistants without vendor lock-in. Each concept is stored as human-readable Markdown with structured YAML frontmatter.
